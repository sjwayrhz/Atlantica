# fenix

Windows 桌面自动化小工具，用 AutoHotkey v2 写的图形界面，打开窗口点按钮或按快捷键就能用。

## 文件

| 文件 | 说明 |
| --- | --- |
| `fenix_GUI.ahk` | 唯一入口，图形界面主脚本 |
| `VirtualDesktopAccessor.dll` | 桌面轮询功能依赖的 DLL，须放在和主脚本同一目录 |
| `FindText.ahk` | 找图标用的 FindText 库（v2 移植版），须放在和主脚本同一目录 |
| `images/StatusBright.png` | 状态图标亮版截图（浅蓝底色），FindText 亮版图案的来源，留着备用，运行不再需要 |
| `images/StatusDark.png` | 状态图标暗版截图（深紫底色），FindText 暗版图案的来源，留着备用，运行不再需要 |
| `images/StatusUnknown.png` | 状态图标未知版截图（全黑、剑也是黑的、只有边框亮），FindText 未知图案的来源，留着备用，运行不再需要 |
| `images/Projector.png` | 放映机图标截图（新尺寸），FindText 放映机新图案的来源，留着备用，运行不再需要 |

## 运行要求

- Windows
- AutoHotkey v2
- 桌面轮询功能需要 `VirtualDesktopAccessor.dll` 和 `FindText.ahk`，且 DLL 版本须和你的 Windows 版本匹配；如果 DLL 加载失败，桌面轮询按钮会被禁用，但点击功能不受影响。

运行方式：双击 `fenix_GUI.ahk` 即可。不需要编译，不需要额外安装。

## 功能 1：桌面轮询（循环）

点「开始：桌面轮询」或按 F11 启动，再点一次或按 F9 就是停止。启动后一直重复下面的循环，停掉之前不会自己停。

**暂停**：按 F8 手动暂停（轮询和开箱子都停），再按一次 F8 继续；动鼠标或者按键盘也会自动暂停，3 秒没动静就自己继续。检测 15 秒的计时暂停时也跟着停（暂停多久就往后顺延多久）。F11 是停止（再启动会从检测重新开始），F9 是全部停止。

### 两个阶段

1. **检测 15 秒**：同时在每个桌面找放映机图标和状态图标，记下各自中心的坐标，光标旁会提示找到没有；这 15 秒只检测、不点图标，按 G 还是按 X 和轮询一样。
2. **一直轮询**：每轮到一个桌面，先激活游戏窗口，再看放映机图标和状态图标，按下面的规则处理，一直重复，停掉之前不会自己停。

### 每轮的步骤

1. 切换到下一个桌面（到最后一个桌面后回到桌面 1，桌面数量按 DLL 返回的实际数量算）
2. 停 0.5 秒
3. 激活游戏窗口：先按窗口标题找（标题是 `Atlantica Online Fenix`，三个桌面标题都一样，但每个桌面只有一个游戏窗口，用 DLL 的 `IsWindowOnCurrentVirtualDesktop` 挑出当前桌面上的那一个激活它，不会切到别的桌面去）；标题找不到时再用图标位置找（先找放映机图标，找不到就找状态图标），鼠标移到图标上、取鼠标下的窗口激活它
4. 激活成功就直接去第 5 步检查，不再点左上角 (212, 57)——那两下点击本来就是为了聚焦窗口，激活成功就没意义了；只有激活失败（标题和图标都找不到）才照旧点 (212, 57)、停 0.5 秒、再原地点一下来聚焦
5. 检查放映机图标和状态图标：放映机图标在、并且是非暗色，就只按一次 X，不按 G；其他情况按一次 G。另外，某个桌面连续非暗色（亮色）超过 20 分钟，就点一下状态图标（怕是误判，实际是暗色却认成了亮色），点完重新计时
6. 按完 G 约 0.05 秒后：放映机图标在，才按一次 X；不在就不按 X；只有放映机图标在、并且是暗色，才点状态图标一下（点完下轮再来检查，不单独验证）；未知图标不点；状态没找到时，先验一下记下的位置是不是亮色，亮色就不点，暗色才点一下记下的位置（有记下位置才点）
7. 回到第 1 步，循环

游戏是窗口模式跑的，不激活的话按 G/X 进不去游戏，以前要手动点一下窗口，现在脚本切完桌面自己激活，不用手动点了。

### 图标和判断规则

**状态图标**是交叉双剑的方形图标，图标里的数字会变。有三种状态：

- **暗色**：暗版图案找到（底色深紫）
- **未知**：未知图案找到（全黑、剑也是黑的、只有边框是亮的），不点，只按 G 和 X
- **非暗色**：暗版和未知都没找到，就当亮色（底色浅蓝）

三个图案都没找到就是**状态没找到**（not found）。放映机在时，按 G、按 X，点之前先验一下记下的位置是不是亮色，亮色就不点，暗色才点一下记下的位置。

**放映机图标**是两个圆盘 + 底座的放映机形状。放映机图标在，才有可能按 X；不在就只按 G，不按 X、不点。

### 找图标的方法

用 FindText，只比明暗形状，不看颜色、不读数字：

- **状态图标**：亮版和暗版各一个 42x35 的黑白图案（阈值 120，从两张截图裁出来的图标方形转的）。亮版是浅底深剑、暗版是深底浅剑，两个图案几乎是反的，互相认不到对方。判断只看暗版图案：暗版找到后，还要在图标中心附近取一个 5x5 网格验亮度（亮点不到一半才是真暗色），亮版底色浅蓝（亮点约 88%），暗版底色深紫（亮点约 16%，顶上有亮边的那张约 32%）。暗版图案万一认错亮版，亮度能把它拦下来，认错就当非暗色。亮版图案只用来定位亮色图标的位置、记下坐标，不参与亮暗判断。未知图案一个 46x41（阈值 82，从截图整个图标转的），和亮版、暗版都认不到对方（交叉验证过），图案本身就够了，不用再验亮度。
- **放映机图标**：两个图案都认，新尺寸 46x36（阈值 79）和旧尺寸 45x39（阈值 68），先找新的，找不到再找旧的。放映机检测的容错比状态图标宽松（0.2，状态图标是 0.1），因为放映机图标在游戏里尺寸会变，太严了容易漏报。
- 图案里数字占的比例很小，换一个数字也在容错范围内；亮版图案里数字和浅底都是亮的，数字变了没影响。
- 记下位置后，只在记录位置附近（中心 ±60/±50）找，范围收小了，避免屏幕别处的误匹配。如果挪动了游戏窗口，停掉重开一次（F11 停、F11 开）重新检测。
- 之前用的 ImageSearch 模板图里带了会变的数字和游戏背景角，数字一变、背景一换就整张对不上，所以完全找不到，才换回 FindText。
- 每次找到都会记到同目录的 `fenix_Find_Log.txt`（时间、桌面、坐标、找到哪个图案、亮点比例），认错了就看这个文件。游戏里图标尺寸变了图案就对不上，到时发一张游戏实屏截图，按实际尺寸重做图案。

桌面轮询区只有两个按钮：**开始**和**暂停**（暂停和 F8 一样，暂停时按钮变成“继续”），没有参数可以填。轮询用的参数固定用配置文件里的值，没保存过就用默认值：每步间隔 1000 毫秒（指上面第 6 步和第 7 步之间的间隔，切换后的两次 0.5 秒停顿是固定的）、按键 `g`、切换后点击的位置 X=212、Y=57。

## 功能 2：开箱子

开箱子就是两点点击和右键点击合并成的功能，同一行三个按钮三选一：

| 按钮 | 效果 |
| --- | --- |
| 左边：两种点击同时操作 | 两点点击和右键点击同时运行 |
| 中间：抽奖 | 只运行右键点击，两点点击不启动 |
| 右边：合成 | 只运行两点点击（点击移动点击），右键点击不启动 |

规则：

- 点另一个按钮会先停掉当前模式，再启动新模式，不会两个模式叠加。
- 再点一次正在运行的按钮就是停止。
- 点「全部停止」会停掉桌面轮询和开箱子；关窗口或点「退出」会全部停止并退出程序。

## 快捷键

- **F8：手动暂停 / 继续**，轮询和开箱子都停，再按一次继续；桌面轮询区里也有一个「暂停」按钮，和 F8 是一样的，暂停时按钮变成“继续”。
- **F11：桌面轮询 开启 / 停止**，和点桌面轮询按钮一样；停止后再启动会从检测重新开始。
- **F12：开箱子 开启 / 暂停**，未运行时启动两种点击同时模式，运行中则暂停（无论哪种模式）。
- **F9：统一暂停**，停掉桌面轮询和开箱子，但不退出程序，窗口留在原地，可以再点按钮或按 F11 / F12 重新开始。
- 之前旧脚本的 F9 是退出，现在改成统一暂停，退出改用窗口里的「退出」按钮或直接关窗口。

### 两点点击（在左边按钮和合成按钮时运行）

- 点 1：(700, 450)，左键点一下
- 点 2：(822, 450)，左键点一下
- 循环：点 1 -> 等 1000 毫秒 -> 点 2 -> 等 2000 毫秒 -> 回到点 1

### 右键点击（在左边按钮和抽奖按钮时运行）

- 位置：(980, 593)，右键
- 间隔：默认每 3500 毫秒一次

界面里可以改的参数：点 1 / 点 2 的坐标、点 1 后和点 2 后的等待时间、右键的位置和间隔。

## 保存配置

- 底部中间的「保存配置」按钮，点一下就把开箱子界面里当前填的值存下来：点 1 / 点 2 坐标、等待时间、右键位置和间隔。桌面轮询的参数不用界面填（用配置文件里的值），保存配置不再写那几项。
- 存到脚本同目录的 `fenix_Config.ini`，下次打开脚本会自动恢复，不用每次重填。
- 注意：保存的是界面里当前填的值；如果某个功能正在运行，点保存不会停掉它，下次启动时才用新值。

## 注意

- 所有坐标都是屏幕坐标，换了分辨率或窗口位置后，需要在界面里改成实际位置。
- 如果某个功能点开始后没有反应，先看窗口里的状态提示，再确认坐标和 DLL 是否正确。
- 改了脚本文件不会让正在跑的脚本自己重载：拉了新版之后，先停掉正在跑的旧脚本，再重新双击打开新版。
