# fenix

Windows 桌面自动化小工具，用 AutoHotkey v2 写的图形界面，打开窗口点按钮或按快捷键就能用。给《王者世界》（Atlantica Online Fenix）用的：桌面轮询、开箱子、快捷切换桌面、录鼠标回放。

## 第一次使用

1. 确认这三个文件在同一个文件夹里：
   - `fenix_GUI.ahk`：唯一入口，图形界面主脚本
   - `VirtualDesktopAccessor.dll`：桌面轮询和快捷切换用的 DLL，版本要和你的 Windows 版本匹配
   - `FindText.ahk`：找图标用的 FindText 库（v2 移植版）
2. 双击 `fenix_GUI.ahk` 打开窗口。不需要编译，不需要额外安装。需要装好 AutoHotkey v2。
3. 如果 DLL 加载失败，窗口里会提示“DLL 加载失败”，桌面轮询和快捷切换的按钮会被禁用，但开箱子不受影响。

> `images/` 里是几张图标截图（状态图标亮版、暗版、未知版、放映机），留着备用，运行的时候不需要。
> 原来的 `SwitchDesktops_DLL_F8.ahk` 和 `TwoPoint_Click_F8.ahk` 已经合并进图形界面，不再使用，已删除。

## 三个功能，一次只能跑一个

桌面轮询、开箱子、快捷切换桌面，同一时间只能跑一个：启动其中一个，会自动停掉另外两个；以后加新功能也按这个规矩。

界面上三个功能之间各有一条横线隔开，底部是全部停止、保存配置、退出。界面里没有多余的提示文字，说明都在这个 README 里。

## 快捷键一览

| 按键 | 作用 |
| --- | --- |
| F8 | 手动暂停 / 继续（轮询和开箱子都停，再按一次继续） |
| F11 | 桌面轮询 开启 / 停止（和点轮询按钮一样；停止后再启动从桌面 1 重新开始） |
| F12 | 开箱子 开启 / 暂停（未运行时启动两种点击同时模式，运行中则暂停） |
| F9 | 全部停止（停掉三个功能，不退出程序，窗口留在原地） |
| \` | 快捷切换 启动 / 停止（飘号键，键盘左上角 1 左边那个，上面是 ~） |
| F1 / F2 / F3 | 切到桌面 1 / 2 / 3（只在快捷切换打开时生效） |
| F5 | 开始 / 停止录制鼠标（只在快捷切换打开时生效；回放中按 F5 是停掉回放） |
| F4 | 点一下回放 1 次；按住约 2 秒是无限回放（只在快捷切换打开时生效；回放中再按 F4 是停掉回放） |

之前旧脚本的 F9 是退出，现在改成全部停止，退出改用窗口里的「退出」按钮或直接关窗口。

## 功能 1：桌面轮询

点「开始：桌面轮询」或按 F11 启动，再点一次或按 F11 就是停止。启动后一直重复下面的循环，停掉之前不会自己停。

**暂停**：按 F8 手动暂停（轮询和开箱子都停），再按一次 F8 继续。轮询区里也有一个「暂停」按钮，和 F8 是一样的，暂停时按钮变成“继续”。动鼠标/键盘自动暂停的功能不要了（装鼠标钩子那行会报错），已经从脚本里清理掉。

### 轮询方式

没有检测阶段了：启动就直接轮询。位置都是固定的：第一次全窗口找并记下位置，以后只在记录位置附近找（又快、屏幕别处的误匹配也进不来）；附近没找到，图标可能挪位置了，再全窗口找一次重新定位。每轮到一个桌面，先激活游戏窗口，再找放映机图标和状态图标，按下面的规则处理，一直重复，停掉之前不会自己停。

### 每轮的步骤

1. 切换到下一个桌面（到最后一个桌面后回到桌面 1，桌面数量按 DLL 返回的实际数量算），并且等切换真正完成（当前桌面号变成目标桌面）再继续，最多等 2 秒——切桌面卡顿时，直接等固定时间可能不够，后面的找图标会读到上一个桌面的画面，坐标记错、点错地方
2. 停 0.5 秒
3. 激活游戏窗口：先按窗口标题找（标题是 `Atlantica Online Fenix`，三个桌面标题都一样，但每个桌面只有一个游戏窗口，用 DLL 挑出当前桌面上的那一个激活它，不会切到别的桌面去）；标题找不到时再用图标位置找（先找放映机图标，找不到就找状态图标），鼠标移到图标上、取鼠标下的窗口激活它
4. 激活成功就直接去第 5 步检查，不再点左上角 (212, 57)——那两下点击本来就是为了聚焦窗口，激活成功就没意义了；只有激活失败（标题和图标都找不到）才照旧点 (212, 57)、停 0.5 秒、再原地点一下来聚焦
5. 检查放映机图标和状态图标：放映机图标在、并且是暗色，就马上点状态图标一下（发现就点，按 G 之前点，点的是这次刚找到的位置；按 G 可能过图，等一会再点位置就变了）；放映机图标在、并且是非暗色，就只按一次 X，不按 G；其他情况按一次 G。另外，某个桌面连续非暗色（亮色）超过 20 分钟，就点一下状态图标（怕是误判，实际是暗色却认成了亮色），点完重新计时
6. 按完 G 约 0.05 秒后：放映机图标在，才按一次 X；不在就不按 X。这里不再点图标（暗色已经在第 5 步发现就马上点过了；未知和状态没找到都不点）。点完状态图标后，鼠标会在图标内部小范围移动 0.5 秒（模拟人工操作），再移到左边的横向黄金分割点（屏幕宽度的 0.382 倍、高 200），免得鼠标挡住图标、影响下次识别；点完再多等 0.5 秒才走——切桌面卡顿时，点下去的输入可能还没处理完，马上切桌面会把这次点击带到新桌面上去，点到新桌面相同位置的按钮
7. 回到第 1 步，循环

游戏是窗口模式跑的，不激活的话按 G/X 进不去游戏，以前要手动点一下窗口，现在脚本切完桌面自己激活，不用手动点了。

### 状态图标的三种状态

状态图标是交叉双剑的方形图标，图标里的数字会变。有三种状态：

- **暗色**：暗版图案找到（底色深紫）
- **未知**：未知图案找到（全黑、剑也是黑的、只有边框是亮的），不点，只按 G 和 X
- **非暗色**：暗版和未知都没找到，就当亮色（底色浅蓝）

三个图案都没找到就是**状态没找到**。放映机在时，按 G、按 X，点之前先验一下记下的位置是不是亮色，亮色就不点，暗色才点一下记下的位置。

**放映机图标**是两个圆盘 + 底座的放映机形状。放映机图标在，才有可能按 X；不在就只按 G，不按 X、不点。

桌面轮询区只有两个按钮：**开始**和**暂停**（暂停和 F8 一样，暂停时按钮变成“继续”），没有参数可以填。轮询用的参数固定用配置文件里的值，没保存过就用默认值：每步间隔 1000 毫秒、按键 `g`、切换后点击的位置 X=212、Y=57。

## 功能 2：开箱子

开箱子就是两点点击和右键点击合并成的功能，同一行三个按钮三选一：

| 按钮 | 效果 |
| --- | --- |
| 左边：两种点击同时操作 | 两点点击和右键点击同时运行 |
| 中间：抽奖 | 只运行右键点击，两点点击不启动 |
| 右边：合成 | 只运行两点点击（点击移动点击），右键点击不启动 |

规则：

- 点另一个按钮会先停掉当前模式，再启动新模式，不会两个模式叠加。
- 再点一次正在运行的按钮就是停止。
- 点「全部停止」会停掉三个功能；关窗口或点「退出」会全部停止并退出程序。

### 两点点击（在左边按钮和合成按钮时运行）

- 点 1：(700, 450)，左键点一下
- 点 2：(822, 450)，左键点一下
- 循环：点 1 -> 等 1000 毫秒 -> 点 2 -> 等 2000 毫秒 -> 回到点 1

### 右键点击（在左边按钮和抽奖按钮时运行）

- 位置：(980, 593)，右键
- 间隔：默认每 3500 毫秒一次

界面里可以改的参数：点 1 / 点 2 的坐标、点 1 后和点 2 后的等待时间、右键的位置和间隔。改完点底部「保存配置」就存下来了，下次打开自动恢复。

## 功能 3：快捷切换桌面

点「开始」打开后，按 F1、F2、F3 切到对应桌面；点「停止」就关掉。

- 默认是停止状态：打开脚本要先点「开始」才能用 1/2/3，「开始」可用、「停止」是灰的；点了「开始」后「开始」变灰、「停止」可用。
- 点「开始」后等 2 秒，脚本会把其他两个桌面上的游戏窗口位置和大小调成和当前桌面一样，这样录的鼠标坐标换桌面也能用。
- 按飘号键 \`（键盘左上角 1 左边那个，上面是 ~）也可以启动 / 停止快捷切换，和点「开始」/「停止」按钮一样；启动和停止时鼠标旁边会提示一下状态（3 秒后自动消失）。
- 关了 F1/F2/F3 就是正常的功能键，不会切桌面。
- 改成 F1–F5 之后，不会再跟战斗里选人的数字键（1–9）冲突了。

### 录鼠标 / 回放（快捷切换开着的时候才能用）

- **按 F5 开始录制**：只录鼠标，不录键盘。录的是每次点下 / 松开左键 / 右键的位置和间隔。
- **再按 F5 停止录制**：录好的动作存在内存里，脚本一关就没了；再按 F5 重新录，会把上一次的盖掉。
- **按 F4 回放**：点一下 F4，在当前桌面把录下来的鼠标动作执行一遍，间隔和录的时候一样（最长 30 秒），光标旁边显示「回放 1/1」，跑完显示「回放完成」。
- **无限回放**：按住 F4 大约 2 秒，松开后先显示「无限回放」提示，1 秒后开始循环回放，一遍接一遍不停；每遍开始时光标旁边显示「无限回放 第 k 次」，状态栏也显示第几遍。
- 回放中再按 F4 可以停掉（F5 也能停）。录的时候、回放的时候，记得先把桌面轮询停掉（启动快捷切换会自动停轮询）。

## 保存配置

- 底部中间的「保存配置」按钮，点一下就把开箱子界面里当前填的值存下来：点 1 / 点 2 坐标、等待时间、右键位置和间隔。桌面轮询的参数不用界面填（用配置文件里的值），保存配置不再写那几项。
- 存到脚本同目录的 `fenix_Config.ini`，下次打开脚本会自动恢复，不用每次重填。
- 注意：保存的是界面里当前填的值；如果某个功能正在运行，点保存不会停掉它，下次启动时才用新值。

## 出问题怎么办

- **拉了新版之后**：改了脚本文件不会让正在跑的脚本自己重载。先停掉正在跑的旧脚本，再重新双击打开新版，不然跑的还是旧版。
- **某个功能点开始后没有反应**：先看窗口里的状态提示，再确认坐标和 DLL 是否正确。
- **状态图标一直认不出来（一直是暗色不被点，或者一直是状态没找到）**：每次找到都会记到同目录的 `fenix_Find_Log.txt`（时间、桌面、坐标、找到哪个图案、亮点比例），把这个文件发过来再查。
- **快捷切换的对齐没生效（三个窗口位置没调成一样）**：点「开始」后等 2 秒，对齐只跑一次；再点「开始」没反应是因为快捷切换已经开着（「开始」是灰的），要先点「停止」再点「开始」才会重新对齐。对齐的记录在同目录的 `fenix_Find_Log.txt` 里，搜 `align:`：`windows found=` 应该是 3（三个桌面各一个游戏窗口），`align: moved` 是挪了哪个窗口。如果 `windows found=1`，说明跑的是旧版（2026-10-27 之前），拉最新版、先停旧脚本再重开。
- **轮询时鼠标点到了别的地方（点到别的桌面的按钮）**：切桌面卡顿、图标挪位置、弹窗挡住图标都可能造成。已改：切桌面后等切换真正完成再继续找图标、点图标；点完状态图标多等 0.5 秒再切下一个桌面；位置都是固定的，第一次全窗口找并记下位置，以后只在记录位置附近找，附近没找到再全窗口找一次重新定位（全窗口也找不到才是不在）；每次点击都记到 `fenix_Find_Log.txt`。如果还出现，把日志发过来再查。
- **挪动了游戏窗口**：位置是第一次全窗口找时记下的，窗口挪了之后附近找不到，会全窗口再找一次重新定位，不用重开。
- **游戏里图标尺寸变了**：图案是按截图的尺寸做的，图标尺寸一变就对不上。到时发一张游戏实屏截图，按实际尺寸重做图案。
- **所有坐标都是屏幕坐标**：换了分辨率或窗口位置后，需要在界面里改成实际位置。
- **打游戏之前顺手关快捷切换**：虽然 F1–F5 不会跟战斗里选人的数字键冲突，但打游戏的时候用不到切桌面，关掉更稳妥。

## 图标是怎么认的（技术说明）

用 FindText，只比明暗形状，不看颜色、不读数字：

- **状态图标**：亮版和暗版各一个 42x35 的黑白图案（阈值 120，从两张截图裁出来的图标方形转的）。亮版是浅底深剑、暗版是深底浅剑，两个图案几乎是反的，互相认不到对方。判断只看暗版图案：暗版找到后，还要在图标中心附近取一个 5x5 网格验亮度（亮点不到一半才是真暗色），亮版底色浅蓝（亮点约 88%），暗版底色深紫（亮点约 16%，顶上有亮边的那张约 32%）。暗版图案万一认错亮版，亮度能把它拦下来，认错就当非暗色。亮版图案用来确认亮色（非暗色），也提供连续非暗色 20 分钟时点击的位置。未知图案一个 46x41（阈值 82，从截图整个图标转的），和亮版、暗版都认不到对方（交叉验证过），图案本身就够了，不用再验亮度。
- **放映机图标**：两个图案都认，新尺寸 46x36（阈值 79）和旧尺寸 45x39（阈值 68），先找新的，找不到再找旧的。放映机检测的容错比状态图标宽松（0.2，状态图标是 0.1），因为放映机图标在游戏里尺寸会变，太严了容易漏报。
- 图案里数字占的比例很小，换一个数字也在容错范围内；亮版图案里数字和浅底都是亮的，数字变了没影响。
- 位置都是固定的：第一次在游戏窗口里面全窗口找并记下位置，以后只在记录位置附近（中心 ±60/±50）找，又快、屏幕别处的误匹配也进不来；附近没找到，图标可能挪位置了（窗口移动、弹窗），再全窗口找一次重新定位，全窗口也找不到才是真的没找到（这时不点）。激活失败时（标题和图标都找不到）才全屏找。每次点击都会记到 `fenix_Find_Log.txt`（时间、桌面、坐标），点错了对着日志能看出来点的是哪一下。
- 之前用的 ImageSearch 模板图里带了会变的数字和游戏背景角，数字一变、背景一换就整张对不上，所以完全找不到，才换回 FindText。
