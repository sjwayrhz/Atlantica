# Atlantica

Windows 桌面自动化小工具，用 AutoHotkey v2 写的图形界面，打开窗口点按钮或按快捷键就能用。

## 文件

| 文件 | 说明 |
| --- | --- |
| `Atlantica_GUI.ahk` | 唯一入口，图形界面主脚本 |
| `VirtualDesktopAccessor.dll` | 桌面轮询功能依赖的 DLL，须放在和主脚本同一目录 |
| `FindText.ahk` | 桌面轮询找图标用的 FindText 库（v2 移植版），须放在和主脚本同一目录 |
| `README.md` | 本说明 |

> 原来的 `SwitchDesktops_DLL_F8.ahk` 和 `TwoPoint_Click_F8.ahk` 已经合并进图形界面，不再使用，已删除。

## 运行要求

- Windows
- AutoHotkey v2
- 桌面轮询功能需要 `VirtualDesktopAccessor.dll` 和 `FindText.ahk`，且 DLL 版本须和你的 Windows 版本匹配；如果 DLL 加载失败，桌面轮询按钮会被禁用，但点击功能不受影响。

运行方式：双击 `Atlantica_GUI.ahk` 即可。不需要编译，不需要额外安装。

## 功能 1：桌面轮询（循环）

点「开始：桌面轮询」或按 F11 启动，再点一次或按 F9 就是停止。启动后一直重复下面的循环，停掉之前不会自己停。

**暂停**：没有单独的暂停按钮，暂停是自动的——只要你动了鼠标或键盘，轮询和开箱子都会马上停下；等你 3 秒没再动鼠标键盘，就自动从停下的地方继续，阶段计时也跟着停（比如空闲 40 分钟的倒计时，暂停多久就往后顺延多久）。脚本自己发的按键和点击不算，不会把自己暂停。想手动暂停就按 F8，再按一次 F8 继续；F11 是停止（再启动会从校准重新开始），F9 是全部停止。

1. **校准 2 分钟**：轮询按 G、X，同时在每个桌面找等待图标和状态按钮，确认位置正常并记下两个点的坐标，光标旁会提示找到的位置。
2. **转亮 2 分钟**：继续轮询，在 2 分钟内把各桌面的状态按钮都点成亮色；点一下就检查一次，确认变亮才算完成；已经亮了的桌面不再点；等待图标还在时不点，等它走了再试。
3. **空闲 40 分钟**：切回桌面 1，继续轮询，但只按 X 不按 G；光标旁一直显示 40 分钟倒计时；这 40 分钟里一直检查状态按钮，不是亮色的就点成亮色。
4. **转暗 2 分钟**：在 2 分钟内把各桌面的状态按钮都点成暗色并确认成功；这 2 分钟里照样轮询按 G、X。
5. **轮询 15 分钟**：只做轮询按 G、X，不判断等待图标和状态按钮的颜色；15 分钟结束后把三个桌面的状态按钮都点成亮色。
6. 然后重复第 3、4、5 步（空闲 40 分钟 → 转暗 → 轮询 15 分钟 → 转亮），一直循环。

每轮轮询（校准、转亮、转暗、轮询阶段）的顺序是：

1. 切换到下一个桌面（到最后一个桌面后回到桌面 1，桌面数量按 DLL 返回的实际数量算）
2. 停 0.5 秒
3. 鼠标左键点击 (212, 57)
4. 再停 0.5 秒
5. 鼠标左键点击一次（当前位置）
6. 按一次 G，约 0.05 秒后看一眼屏幕：只有看到等待图标、没看到状态按钮时才按一次 X（空闲阶段只按 X，不按 G，同样只有看到等待图标时才按）
7. 校准 / 转亮 / 转暗 / 空闲阶段：在这个桌面找一次图标（校准记坐标，转亮 / 转暗 / 空闲决定点不点）
8. 回到第 1 步，循环

名字说明：**等待图标**是 FindText 找的那个紫底银色图标，它在的时候状态按钮还没出来，只能等它走；**状态按钮**是圆形金框圆盘，亮色和暗色来回切换，点击它的圆盘中心就能切换，点完会再找一次确认颜色真的变了。按 X 的规则：只有看到等待图标、没看到状态按钮时才按 X，看到状态按钮时不按 X，两个都没看到也不按。

找状态按钮的方法：先用容错 0.1 找，找不到再用宽松容错 0.2；校准记下位置后，只在记录位置附近找，避免屏幕别处的误匹配；宽松容错找到的会再用盘心亮度确认一次（亮色约 221、暗色约 58，阈值 140）。注意：暗色图案在宽松容错下会在屏幕左上角误匹配，所以没校准记录时暗色只用 0.1。如果挪动了游戏窗口，停掉重开一次（F11 停、F11 开）重新校准。

界面里可以改的参数：

- 每步间隔：默认 1000 毫秒，指第 5 步和第 6 步之间的间隔（切换后的两次 0.5 秒停顿是固定的）
- 按键：默认 `g`
- 切换后点击的位置：默认 X=212、Y=57

## 功能 2：开箱子

开箱子就是两点点击和右键点击合并成的功能，同一行三个按钮三选一：

| 按钮 | 效果 |
| --- | --- |
| 左边：两种点击同时操作 | 两点点击和右键点击同时运行 |
| 中间：抽奖 | 只运行右键点击，两点点击不启动 |
| 右边：合成 | 只运行两点点击（点击移动点击），右键点击不启动 |

规则：

- 点另一个按钮会先停掉当前模式，再启动新模式，不会两个模式叠加。
- 再点一次正在运行的按钮就是停止。
- 点「全部停止」会停掉桌面轮询和开箱子；关窗口或点「退出」会全部停止并退出程序。

## 快捷键

- **F8：手动暂停 / 继续**，轮询和开箱子都停，再按一次继续；不用 F8 也行，动鼠标 / 键盘会自动暂停，3 秒无操作后自动继续。
- **F11：桌面轮询 开启 / 暂停**，和点桌面轮询按钮一样。
- **F12：开箱子 开启 / 暂停**，未运行时启动两种点击同时模式，运行中则暂停（无论哪种模式）。
- **F9：统一暂停**，停掉桌面轮询和开箱子，但不退出程序，窗口留在原地，可以再点按钮或按 F11 / F12 重新开始。
- 之前旧脚本的 F9 是退出，现在改成统一暂停，退出改用窗口里的「退出」按钮或直接关窗口。

### 两点点击（在左边按钮和合成按钮时运行）

- 点 1：(700, 450)，左键点一下
- 点 2：(822, 450)，左键点一下
- 循环：点 1 -> 等 1000 毫秒 -> 点 2 -> 等 2000 毫秒 -> 回到点 1

### 右键点击（在左边按钮和抽奖按钮时运行）

- 位置：(980, 593)，右键
- 间隔：默认每 3500 毫秒一次

界面里可以改的参数：点 1 / 点 2 的坐标、点 1 后和点 2 后的等待时间、右键的位置和间隔。

## 保存配置

- 底部中间的「保存配置」按钮，点一下就把界面里当前填的全部值存下来：桌面轮询的间隔、按键、切换后点击位置，开箱子的点 1 / 点 2 坐标、等待时间、右键位置和间隔。
- 存到脚本同目录的 `Atlantica_Config.ini`，下次打开脚本会自动恢复，不用每次重填。
- 注意：保存的是界面里当前填的值；如果某个功能正在运行，点保存不会停掉它，下次启动时才用新值。

## 注意

- 所有坐标都是屏幕坐标，换了分辨率或窗口位置后，需要在界面里改成实际位置。
- 如果某个功能点开始后没有反应，先看窗口里的状态提示，再确认坐标和 DLL 是否正确。
