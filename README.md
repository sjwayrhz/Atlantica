# Atlantica

Windows 桌面自动化小工具，用 AutoHotkey v2 写的图形界面，不用记快捷键，打开窗口点按钮就能用。

## 文件

| 文件 | 说明 |
| --- | --- |
| `Atlantica_GUI.ahk` | 唯一入口，图形界面主脚本 |
| `VirtualDesktopAccessor.dll` | 桌面轮询功能依赖的 DLL，须放在和主脚本同一目录 |
| `README.md` | 本说明 |

> 原来的 `SwitchDesktops_DLL_F8.ahk` 和 `TwoPoint_Click_F8.ahk` 已经合并进图形界面，不再使用，已删除。

## 运行要求

- Windows
- AutoHotkey v2
- 桌面轮询功能需要 `VirtualDesktopAccessor.dll`，且 DLL 版本须和你的 Windows 版本匹配；如果 DLL 加载失败，桌面轮询按钮会被禁用，但点击功能不受影响。

运行方式：双击 `Atlantica_GUI.ahk` 即可。不需要编译，不需要额外安装。

## 功能 1：桌面轮询

点「开始：桌面轮询」，再点一次就是停止。

每轮的顺序是：

1. 切换到下一个桌面（到最后一个桌面后回到桌面 1，桌面数量按 DLL 返回的实际数量算）
2. 停 0.5 秒
3. 鼠标左键点击 (212, 57)
4. 再停 0.5 秒
5. 鼠标左键点击一次（当前位置）
6. 按一次 G
7. 回到第 1 步，循环

界面里可以改的参数：

- 每步间隔：默认 1000 毫秒，指第 5 步和第 6 步之间的间隔（切换后的两次 0.5 秒停顿是固定的）
- 按键：默认 `g`
- 切换后点击的位置：默认 X=212、Y=57

## 功能 2：点击功能

两点点击和右键点击已经合并成一个功能，左右两个按钮二选一：

| 按钮 | 效果 |
| --- | --- |
| 左边：两种点击同时操作 | 两点点击和右键点击同时运行 |
| 右边：只做右键点击 | 只运行右键点击，两点点击不启动 |

规则：

- 点另一个按钮会先停掉当前模式，再启动新模式，不会两个模式叠加。
- 再点一次正在运行的按钮就是停止。
- 点「全部停止」会停掉桌面轮询和点击功能；关窗口或点「退出」会全部停止并退出程序。

## 停止快捷键

- **F9：全部停止**，停掉桌面轮询和点击功能，但不退出程序，窗口留在原地，可以再点按钮重新开始。
- 之前旧脚本的 F9 是退出，现在改成停止，退出改用窗口里的「退出」按钮或直接关窗口。

### 两点点击（只在左边按钮时运行）

- 点 1：(700, 450)，左键点一下
- 点 2：(822, 450)，左键点一下
- 循环：点 1 -> 等 1000 毫秒 -> 点 2 -> 等 2000 毫秒 -> 回到点 1

### 右键点击（左右两个按钮都会运行）

- 位置：(980, 593)，右键
- 间隔：默认每 3500 毫秒一次

界面里可以改的参数：点 1 / 点 2 的坐标、点 1 后和点 2 后的等待时间、右键的位置和间隔。

## 注意

- 所有坐标都是屏幕坐标，换了分辨率或窗口位置后，需要在界面里改成实际位置。
- 如果某个功能点开始后没有反应，先看窗口里的状态提示，再确认坐标和 DLL 是否正确。
